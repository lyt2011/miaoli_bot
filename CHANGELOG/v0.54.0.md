# v0.54.0 - 2026-11-15

> 🧱 **模型客户端工厂从主包搬进 `base_llm`，`api` 的两个查询函数改为返回对象**。主包从此不再 import 任何 langchain 供应商实现，也不再靠 `model_dump()` 把配置对象降级成字典往外递。

## Added

- `plugins/base_llm/consts/`：`CLIENT_MAPPING`（`deepseek` / `openai` / `anthropic` → langchain 实现类），从主包 `api/llm_ops.py` 迁入。
- `plugins/base_llm/utils/get_client_cls.py`：按名字取实现类，从主包的 `_get_client_cls` 改名迁入（去掉下划线前缀，与「文件名 = 函数名」对齐）。
- `plugins/base_llm/core/build_client.py`：`build_client(provider_name, model_name)` 读根配置的 `llm` 段建 `BaseChatModel`；两个名字必须显式传，不再从 `config.llm` 兜默认值。
- `plugins/base_nodes/metadata.toml` 增加 `base_llm` 依赖，让客户端工厂在 `build_client` 节点之前就位。
- `SubPluginConfig` 增加 `overwrite: Dict[str, dict]`（默认空表）：键是子插件包名，值是整份替换该插件配置的字典。
- `main.py` 把 `config.sub_plugin.overwrite` 传给 `Loader.load_plugins()`，覆盖表因此有了来源。

## Changed

- `miaoli_bot.api.get_model_info()` / `get_provider_info()` 返回 `LLM` / `Provider` 对象，不再返回 `model_dump()` 之后的字典；查不到对应供应商或模型时抛 `ProviderNotFound` / `ModelNotFound`，替代原来返回 `None`、再由调用方 `.model_dump()` 撞 `AttributeError` 的路径。
- `api/llm_ops.py` 去掉 `_get_provider` / `_get_model` 两个私有查表方法，查表并入两个公开函数。
- `plugins/base_nodes/nodes/build_client.py` 改为先从根配置取出 provider / model 名字，再调 `base_llm.api.build_client()`。
- `plugins/base_nodes/nodes/compact.py` 的压缩门槛改读对象属性（`model.context_window - model.max_tokens`）。
- `plugins/base_llm/api/` 只转出 `build_client` / `call_llm` 两个能力；`CLIENT_MAPPING` / `get_client_cls` / `is_retriable` / `MaxRetryLimitError` 各从 `base_llm.consts` / `base_llm.utils` / `base_llm.errors` 取。
- `core/plugin/loader.py` 的 `load_plugins` 接收按插件包名索引的配置映射，逐插件透传给 `Plugin.load`；`core/plugin/plugin.py` 的 `load(config)` 允许用传入配置替代 `config.yaml`，并在注入前展开 `$workspace`。

## Removed

- `miaoli_bot.api.build_client()` 及其对外导出（`api.__all__` 15 → 14 项）。
- `api/llm_ops.py` 里的 `CLIENT_MAPPING` 与 `_get_client_cls`。
- 主包对 `langchain_openai` / `langchain_deepseek` / `langchain_anthropic` 的 import —— 只剩 `base_llm` 认识供应商实现。

## Note

- **破坏性**：`miaoli_bot.api.build_client` 不再存在，客户端构建改从 `base_llm.api` 取；`get_model_info` / `get_provider_info` 的返回值从字典变对象，按键取值的地方要改成属性访问。
- `ClientNotFound` / `ModelNotFound` / `ProviderNotFound` 仍归主包 `errors/`，需要就地 `from miaoli_bot.errors import ...`，不经 `base_llm.api` 重新导出。
- `load_plugins(configs)` 是必需参数：主包 `main.py` 传的是 `config.sub_plugin.overwrite`，缺省空表时行为与旧版一致。
