# v0.37.0 - 2026-11-03

> 🧱 **`miaoli_pipeline` 并回主包，`core/` 重新分层，子插件的注册方式从「一个事件一对方法」改成一个 `on()` 返回注销函数**。根配置新增 `buffer` 段，`SHARE_STORE` 新增 `EVENT_BUFFER` 键。

图管线原来是一个独立仓库、独立安装的包：`manifest.toml` 里写不了（`pip_dependencies` 只接受「包名 + PEP 440 约束」，它没上 PyPI），部署时要额外 `pip install /path/to/miaoli_pipeline`，本地与服务器各装一次、版本各自漂移。现在它的全部源码就是主包里的 `core/graph_pipeline/`，部署回到「整目录同步 + 重启」一件事。

注册器原来给每个图事件配一对 `on_<事件>()` / `remove_<事件>()`，加一个新事件要在三个地方各补一次，而 `on_close` 里的摘除顺序还得和 `on_load` 的注册顺序手工对齐。现在只剩 `on(event, func, priority)`，它返回一个注销函数 —— 子插件把返回的闭包收进 `self.undo_list`，`on_close` 里遍历调用即可，注册与摘除天然成对。

工具表也不再直接把 `ToolRegistry` 递给外面：每轮用 `to_surface()` 生成一份 `ToolSurface` 快照放进 `runtime.context["tool_surface"]`，`pick_tools` 之类的节点只能改快照，改不到注册器本身。

## Added

- `core/graph_pipeline/`：图管线本体（原独立包 `miaoli_pipeline`）—— `graph_pipeline.py`（`GraphPipeline`：`register_handler` / `unregister_handler` / `wire` / `compile` / `ainvoke`）、`actions/`（`BaseNodeAction` 与 `Continue` / `Goto` / `Abort`）、`channels/section_patch.py`（`SectionPatch`）、`runtime/handler.py`（单个事件内按 `priority` 降序的处理器编排）。
- `core/handler_registry.py`：`HandlerRegistry`，只留 `on(event, func, priority=0) -> Callable[[], None]`。
- `core/tool/`：`ToolRegistry`（`contains` / `register` / `unregister` / `to_surface`）与 `ToolSurface`（以 `Dict[tool.name, tool]` 保存的工具表副本，`add` / `delete` / `contains` / `tools`）。
- `core/ob11_buffer/event_buffer.py`：`EventBuffer` —— `record` 从头插入（满载自动淘汰最旧）、`pop(count)` 取最新 `count` 条、`__len__`。
- `protocols/`（顶层集中层）：`BaseTimer` / `PluginProtocol` / `BaseNodeAction` / `BaseCheckpointerSaverAdapter` 四个抽象基类从 `core/` 各子目录搬到一处。
- `errors/`：`agent_aborted.py`，以及原先藏在 `core/plugin/errors/` 的五个加载期异常（`BasePluginError` / `NotAPackageError` / `MetadataMissingError` / `EntryClassNotFound` / `RepeatDependenceError`）。
- `models/config/buffer_config.py`：`BufferConfig`（`size` 默认 `30`），并进 `PluginConfig.buffer`。
- `api/tool_ops.py`：`register_tool(tool)` —— 注册工具并返回注销函数；同名工具只打一行 warning，不拦截。
- `utils/pipeline_helper.py`：图管线的合并辅助（`merge_into_state` / `merge_into_updates` / `is_none_action` / `is_update_action` / `apply_deltas`）。
- `plugins/ob11_buffer/`：`get_qq_unread_messages` 工具 —— 按 `count` 从 `EventBuffer` 取最新未读、翻成「旧 → 新」后返回 `{"messages", "metadata"}`（`metadata` 含 `expectation_read` / `actual_read` / `remaining`）。
- `SHARE_STORE` 新增键 `EVENT_BUFFER`。

## Changed

- `main.py`：`GraphPipeline` / `AgentAborted` / `EventBuffer` 改从 `miaoli_bot.core` 导入；`on_load` 装配 `EventBuffer(size=config.buffer.size)`，`on_close` 里一并 `drop`；新增 `record_anything`（`@registrar.on_message()`），把每条私聊 / 群聊事件记进缓冲；`ainvoke` 的 `context` 由 `{"tools": tool_registry.tools}` 改为 `{"tool_surface": tool_registry.to_surface(), "custom_status": ["main"]}`。
- `HandlerRegistry`：11 对 `on_<事件>` / `remove_<事件>` 方法合并成一个 `on(event, func, priority)`，返回注销函数。
- 工具注册链路：子插件不再用 `get_tool_registry()` 直接拿注册器，改用 `api.register_tool()`；每轮工具表以 `ToolSurface` 快照进 `runtime.context["tool_surface"]`，`call_llm`（`bind_tools`）、`pick_tools`（按权限 `delete`）、`mcp_adapter`（去重后 `add`）、`tool_permission_manager` 全部改读快照。
- `models/config/` 七个模块移动并改名：`account.py` → `account_config.py`（`Account` → `AccountConfig`）、`check_pointer.py` → `checkpointer_config.py`（`CheckPointerConfig` → `CheckpointerConfig`）、`plugin.py` → `plugin_config.py`、`provider.py` → `provider_config.py`、`split.py` → `reply_split_config.py`（`SplitConfig` → `ReplySplitConfig`）、`sub_plugin.py` → `sub_plugin_config.py`、`typing.py` → `typing_speed_config.py`（`TypingConfig` → `TypingSpeedConfig`）。
- `consts/__init__.py`：补 `EVENT_BUFFER` 导出。
- `core/scheduler/`：`BaseTimer` 改从顶层 `protocols/` 引入，`Once` / `Every` 直接按文件导入。
- 18 个内置子插件：`get_handler_registry().on_<事件>(...)` → `registry.on(事件常量, ...)` 并收进 `self.undo_list`，`on_close` 遍历调用；`miaoli_pipeline.*` 的导入改到 `miaoli_bot.core.*`，事件常量改从 `miaoli_bot.consts` 导入。
- 文档：主 README 中英双份同步（结构树、数据流、子插件表、配置表、依赖表、项目状态）。

## Removed

- 外部依赖 `miaoli_pipeline`：部署不再需要 `pip install /path/to/miaoli_pipeline`，中英 README 的安装注记一并删除。
- `core/registries/`（两个注册器的旧位置）、`core/plugin/protocols/`、`core/plugin/errors/`、`core/scheduler/protocols/`、`core/check_pointer_adapters/protocols/`。
- `core/plugin/models/topology_runtime/`：合并成单文件 `plugin_topology_runtime.py`。
- OB11 缓冲的 store 层：`BufferStore` 协议、`InMemoryStore`、`models/config/buf_stores/` 配置工厂 —— 三层抽象最后只是把 `deque` 包了三遍。
- `api.registry_ops` 的 `get_tool_registry`（工具注册改走 `register_tool` + `tool_surface`）。
- `plugins/time_injector/`：时间注入子插件。

## Note

- **子插件的 `on_close` 必须改成遍历 `self.undo_list`**：仓库内 18 个已同步，仓库外的自定义子插件若还在调 `HandlerRegistry.remove_*()` / `ToolRegistry.remove()` 会直接 `AttributeError`。
- `EventBuffer` 是**进程内**缓冲，重启即空；写入方（`record_anything`）与读取方（工具）必须同一个进程，多进程部署不共享。
- 缓冲积压超过 `count` 时中间的消息会被静默丢弃，`metadata` 只有 `actual_read`，没有 `dropped` 字段。
- `GraphRuntimeContext.tools` 字段在改走 `tool_surface` 之后已无人读取，暂时保留未删。
