# v0.27.1 - 2026-10-21

> 🧹 **统一补齐全仓库 `.py` 的末尾换行**。66 个 Python 文件的最后一行没有以换行符结束，在 `git diff` 上表现为 `\ No newline at end of file`，ruff 也会报 `W292`。

文本文件的最后一行以换行符结束是 POSIX 的定义。缺了它，之后任何往这些文件尾部追加内容的改动，都会和「补换行」混进同一个 diff，看不出到底改了什么。

`config.example.yaml` 这份模板漏了 `with_path`（0.27.0 只改了代码和插件 README），本版加上了这一行。

## Added

- `plugins/intent_recognition/config.example.yaml`：新增 `with_path: true` 一行。

## Changed

- 全仓库 66 个 `.py` 文件在末尾追加换行符。只追加、不删除，每个文件的 diff 都是 1 删 1 增。

## Note

- 其中 2 个文件（`models/config/typing.py`、`plugins/intent_recognition/models/plugin_config.py`）的最后一行是「只含空白字符且没有结尾换行」——只判断「最后一行 `strip()` 后是否为空」会漏掉它们，判据要看**最后一个字节是不是 `\n`**。
- 17 个 0 字节的 `__init__.py` 未改动，空文件不需要换行符。
- 存的 `.py` 里没有 CRLF 行尾，所有改动都只涉及文件末尾那一个字节。
