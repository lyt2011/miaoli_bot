# v0.34.1 - 2026-11-02

> 🧹 **导入分块与列对齐规则重做**。上一版的导入只切成「第三方 → 同包 → 内置 → 普通」四段，同包相对导入与跨包自引用挤在同一块里；列对齐则统一到整块最长的前缀，`from .utils import (...)` 这类短行被推到很远。这一版把自引用拆成两块，并让换行导入成为对齐的组尾。

## Changed

- **导入分块的顺序**扩成六段：`from __future__` → 第三方 from（按顶层包名各成一块）→ 跨包自引用 `from miaoli_bot.x` → 同包相对导入 `from .` / `from ..` → 内置 from → 普通 `import`；块与块之间空一行。
- **列对齐的分组**：块内再按「换行导入（行尾是左括号）之后断开」切组 —— 换行导入可以跟上面的行粘在一起对齐，它下面的行另起一组。`main.py` 里 `from .core` 与两条 `from .core.check_pointer_adapters` 因此同列，`from .models` / `from .utils` / `from .consts` 各自回到自己的下一档。
- 全仓 `.py` 按新规则重排，块内仍按语句字符数从短到长。

## Docs

- `README.md` / `README/en.md` 的目录树同步到 `core/` 的新位置，删掉已不存在的 `adapters/`、`protocols/`、`stores/` 三个节点；「协议先行」「checkpointer 适配层」「共享存储」三条按现状改写。
- 两份 README 的「项目状态」新增一条导入约定。
- 两份 README 的版本行同步到 0.34.1（`README/en.md` 此前停在 0.33.1）。
