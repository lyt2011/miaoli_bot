# v0.48.2 - 2026-11-11

> 🔍 **`web_search` 会自我介绍了**。工具挂上去模型未必知道什么时候该用，于是补一段提示词段说明用法；但它不写成「必须搜」，只提高搜索倾向 —— 实测强制措辞带不来增益。

## Added

- `plugins/web_search/consts/prompt.py`：新增 `HELPER_PROMPT`（665 字符），四节 —— 什么时候值得先查一次 / 怎么搜 / 搜完怎么用 / 适用范围。硬编码字符串，不读外部文件、不加配置项。
- `plugins/web_search/nodes/inject_helper.py`：新增 `inject_helper`，把 `HELPER_PROMPT` 写进 `prompts` 的 `web-search-helper` 段。
- `plugins/web_search/main.py`：`on_load` 在注册工具之后再注册 `inject_helper`（`ON_AGENT_START` + `NORMAL`），`undo_list` 收口；`enable: false` 时工具与节点一起跳过。

## Changed

- 提示词措辞定调为**提高搜索倾向**而非强制：`count` 默认 1~3 条（`deepseek` 后端单条正文约 2,100 字符，`count: 10` 一次约 9.7k token，模型默认就爱填 10）；同名歧义时列候选反问、不挑一个硬套；二次搜索只在首次为空或无关时允许一次。

## Docs

- `plugins/web_search/README.md`：`on_load` 从三件事改成四件事；新增「提示词段」节（挂载点、段名、四节内容、为什么不下硬指令）；「Token 开销」补 2026-11-11 在 `deepseek` 后端的复测数据（`count: 3` → 6,246 字符 / 约 2,935 token，`count: 10` → 20,722 字符 / 约 9,739 token）。
- `README.md` / `README/en.md`：联网搜索特性条与内置子插件表补上 `web-search-helper` 段与 `inject_helper`；英文目录树 `web_search/` 补 `nodes/`。

## Note

- 定调依据是一次 A/B 实测（`deepseek-v4.1-flash`，13 个用例、每格 N=2~3，对照组从同一份系统提示里只摘掉 `<web-search-helper>` 段）：模型对「X 是什么梗」与时效类问题本来就 100% 触发搜索，对「某人在干嘛」与孤立短词本来就 0% 触发 —— 强制措辞测不出增益，个别用例上反而更爱搜。真正缺的是 `count` 用法，所以这一版只提高权重。
