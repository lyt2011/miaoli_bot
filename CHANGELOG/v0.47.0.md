# v0.47.0 - 2026-11-11

> 🗄️ **`prompts` 不再进 checkpoint**。`SectionPatch.checkpoint()` 交回整个段落字典，于是每轮跑图都往 `checkpoint_blobs` 里写一份「这一轮的提示词段集合」—— 而这堆东西每轮都由子插件现推、`build_prompt` 现拼，存档从头到尾没有阅读者。新增 `UntrackedSectionPatch`：`checkpoint()` 直接返回 `MISSING`，langgraph 侧只写 `v is not MISSING` 的通道，整条通道就此不进快照。

## Added

- `core/graph_pipeline/channels/untrack_section_patch.py`：`UntrackedSectionPatch(SectionPatch)` ——
  - `checkpoint()` 返回 `MISSING`：该通道不出现在 `channel_values` 里，落盘时被跳过；
  - `copy()` 返回 `self.__class__(...)`：基类的 `copy()` 与 `from_checkpoint()` 都写死了 `SectionPatch`，不覆盖会在 langgraph 复制 / 恢复通道时退化回会落盘的基类（`from_checkpoint()` 现在已经走 `self.__class__`，只有 `copy()` 需要显式覆盖）。
- 导出链路 `core.graph_pipeline.channels` → `core.graph_pipeline` → `core` 三层都加了 `UntrackedSectionPatch`。

## Changed

- `models.GraphState.prompts` 的通道由 `SectionPatch` 换成 `UntrackedSectionPatch`。
- `core/graph_pipeline/__init__.py` 里 `SectionPatch` 改从 `.channels` 一层导入，与 `UntrackedSectionPatch` 同批；导入块对齐随之收窄。
- `plugins/time_injector/nodes/helper_inject.py` 删掉 `def` 行与 docstring 之间、docstring 与 `return` 之间的空行。

## Note

- 「不落盘」是按**通道**生效，不是按 key：同一张图里的其它 `SectionPatch` 通道照常进快照。
- 中断恢复不受影响。`from_checkpoint(MISSING)` 恢复出来的是空通道，而 `prompts` 每一轮都由 `inject_soul` / `inject_output_protocol` / `meme_ops` / `time_injector` 等节点重新写入，没有任何节点读上一轮的残值。
- 这条通道依赖 langgraph 内部约定：`pregel/_checkpoint.py` 里只有 `v is not MISSING` 才把值塞进 `channel_values`。升级 langgraph 时要重新确认这个分支还在。

## Docs

- README（中 / 英）版本号同步到 0.47.0；`GraphState` 的描述两处都从「`messages` / `prompts` 两者都进 checkpoint」改成「`messages` 进、`prompts` 走不落盘通道」；目录树的 `channels/` 补上新文件。
