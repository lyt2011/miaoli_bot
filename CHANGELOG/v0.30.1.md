# v0.30.1 - 2026-10-29

> 📖 **新增英文 README，中英两版在顶部互相链接**。内容与中文版同结构、同章节，供非中文读者和搜索引擎抓取。

本项目 README 一直是中文单版，GitHub 仓库页与外部搜索只拿得到仓库描述那一行。英文版按中文版的结构整体翻译（功能特性 / 架构图 / 目录结构 / 数据流 / 内置子插件 / 安装与使用 / 配置表 / 依赖 / 项目状态），技术标识符、字段名、优先级常量、路径一律保持原样，只在叙述上转成英文。

英文版放在 `README/en.md`，与 `CHANGELOG/` 的做法一致：根目录只留默认语言的入口文件，其它语言的正文收进同名目录。中文版仍是根 `README.md`（GitHub 渲染入口、搜索结果落地页），不搬进 `README/` —— 否则要么根目录变成空壳页，要么同一份正文存两遍。

## Fixed

逐条对照代码核了一遍两版 README，修正以下与实现不符的描述（中英同步）：

- `prompt_builder` 一行把 `state["prompts"]` 写成 `state["prompt"]`（0.28.0 已改名）。
- `orphan_tool_fixer` / `pending_tool_fixer` 的注册点写成 `on_before_request` + `priority=2` / `priority=3`，实际两者都挂在 `on_request`、优先级都是 `NORMAL+2`。
- `tool_attachment_fixer` 的方法名写成 `on_tool_calling`，`HandlerRegistry` 上的真实方法名是 `on_tool_call`（`ON_TOOL_CALLING` 是事件常量）。
- 依赖表把 `GraphPipeline` 的方法写成 `register`，0.29.0 起是 `register_handler`（配套 `unregister_handler`）。
- 安装步骤与依赖表把 pip 包名写成 `ncatbot`，`manifest.toml` 里声明的是 `ncatbot5`（导入名才是 `ncatbot`）。
- `miaoli_pipeline` 的版本约束由 `>=1.0.2` 改为 `>=1.1.0`。
- 共享存储键漏了 `HANDLER_REGISTRY`（实际共 8 个）。
- `api/` 目录树漏了 `registry_ops.py`，门面层说明漏了 `get_handler_registry` / `get_tool_registry` 与 `get_provider_info`。
- 压缩提示词与表情包帮助文档的路径写成 `data/*.md`，实际在 `plugins/context_compactor/data/` 与 `plugins/meme_ops/data/` 下。
- `web_search` 的请求地址来自子插件 `config.yaml` 的 `api_url`，不是写死的；补上模板里的 langsearch 地址。
- 优先级档位原写「九档等比阶梯」，9 个常量（9999 / 1000 / 100 / 10 / 0 / -10 / -100 / -1000 / -9999）不是等比，改为「九档阶梯」。
