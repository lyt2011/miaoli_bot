# v0.48.3 - 2026-11-12

> 🧹 **一次纯结构清理**。多代理审查翻了整棵目录树，挑出来的都是「东西放错位置 / 名字对不上 / 早就没人用」这一类毛病：没有一处改到运行时行为。两条文件级问题（跨两层导入、拼写错误）顺手修掉，一个从 0.34.0 起就躺在仓库里没人用的调度器清出去。

## Changed

- `core/check_pointer_adapters/` → `core/checkpointer_adapters/`：目录名不再把 `checkpointer` 拆成 `check_pointer`；目录内 `memory.py` / `sqlite.py` / `postgresql.py` 一并改成 `in_memory_adapter.py` / `sqlite_adapter.py` / `postgresql_adapter.py`，与三个类名对齐。
- `core/compact/compact.py` → `compact_now.py`，`core/compact/utils/calculate.py` → `base_calculate.py`，`core/graph_pipeline/channels/untrack_section_patch.py` → `untracked_section_patch.py`：文件名补齐到与主函数 / 类名一致。
- 三处导入改走导出层：`core/graph_pipeline/__init__.py` 与 `graph_pipeline.py` 的 `from .runtimes.handler import Handler` 改成 `from .runtimes import Handler`；`core/graph_pipeline/actions/{abort,continue_,goto}.py` 的 `from ....protocols.node_action import BaseNodeAction` 改成 `from ....protocols import BaseNodeAction`。
- `tests/test_utils__writing.py` 拆成 `tests/test_config_ops.py`（`test_workspace_injector`）与 `tests/test_sugar.py`（`test_id_concatenate`）：原来的文件名对应不到任何源模块，两个不同模块的用例挤在一个文件里。

## Removed

- `core/scheduler/`（`Job` / `Every` / `Once` + `timers/`）与 `protocols/timer.py`（`BaseTimer`），以及 `core/__init__.py` / `protocols/__init__.py` 里对应的导入与 `__all__` 条目。唤醒早已由 `main.py` 的 `tick` 任务接管，这套调度器只剩自己引用自己。

## Fixed

- `models/graph_runtime_context.py`：`from ..core.tool import ToolSurface` 跨了两层，改成 `from ..core import ToolSurface`。
- `plugins/mcp_adapter` 的 `ToolObtainanle` → `ToolObtainable`（协议定义、`protocols/__init__.py` 导出、`core/mcp_client_registry.py`、`models/runtimes/mcp_client.py` 共 7 处）。

## Note

- 全部改动不涉及运行时行为：子插件仍然只从 `miaoli_bot.api` / `models` / `core` / `consts` 四层取符号，`base_nodes/nodes/compact.py` 用到的 `CompactFailed` / `base_calculate` / `compact_now` 三个导出都在。
- 删调度器前核过仓内与兄弟仓库（`miaoli_qq_channel`、`miaoli_smart_waker`）：除 `core/__init__.py` 自己的再导出外没有任何消费者。`core` / `protocols` 的 `__all__` 分别少 4 / 1 个名字，按补丁版处理。
- 审查还点了 `core/graph_runner.py`、`core/tool/`、五个 `sugar.py`、`protocols/*.py` 这类「文件名 ≠ 里面的符号」的纯改名项，以及 `api/llm_ops.py` 实现下沉、`utils/pipeline_helper.py` 归属`core/graph_pipeline/`、三个相同的 `plugin_config.py` 收敛 —— 这些没动，留作单独一次整理。
