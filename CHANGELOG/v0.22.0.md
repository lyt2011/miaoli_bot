# v0.22.0 - 2026-10-20

> 🧱 **图管线抽出为独立包 [`miaoli_pipeline`](https://github.com/lyt2011/miaoli_pipeline)，提示词改为按键分段的 `SectionPatch` 通道，压缩拆成「守卫 → 压缩 → 收尾」三段事件（破坏性）**。

三件事连在一起：图管线不再是本仓库的私有代码，而是一个可独立版本化的依赖；提示词不再是「一个字符串谁写谁覆盖」，而是「一张表各写各的段」；压缩不再是藏在 `on_before_request` 里的一个 `if`，而是图上有名有姓的三个事件。

## Added

- **依赖 [`miaoli_pipeline`](https://github.com/lyt2011/miaoli_pipeline)**（`>=1.0.1`）：`GraphPipeline` / `BaseNodeAction`（`Continue` / `Goto` / `Abort`）/ `Handler` / `AgentAborted` 从本仓库迁出，`SectionPatch` 通道为首次引入；本仓库只保留 `consts` 里的事件名与优先级、`core.Registry` 的注册门面。分发名 `miaoli-pipeline`，包名 `miaoli_pipeline`。
- **三个压缩事件**：`ON_BEFORE_COMPACT` / `ON_COMPACT` / `ON_AFTER_COMPACT`，`GRAPH_EVENTS` 由 8 个变 11 个，位置在 `ON_TURN_START` 与 `ON_BEFORE_REQUEST` 之间。
- **`Registry.on_before_compact` / `on_compact` / `on_after_compact`** 三个注册方法。
- **`base_topology` 三个默认跳转节点**：`on_before_compact`（默认不压缩 → `ON_BEFORE_REQUEST`）、`on_compact`（→ `ON_AFTER_COMPACT`）、`on_after_compact`（**跳回 `ON_TURN_START`**）。
- **`context_compactor` 的 `should_compact` 守卫节点**：算 token、判阈值，返回 `Goto(ON_COMPACT)` 或 `Goto(ON_BEFORE_REQUEST)`。
- **`prompt_builder` 子插件**：`build_prompt` 在 `ON_BEFORE_REQUEST`（`priority=NORMAL+1`）把 `state["prompt"]` 的键值拼成 `<key>value</key>` 段落，用 `Overwrite` 放到 `messages[0]`；内容未变时返回 `None`，不白写一次 `Overwrite`。

## Changed

- **`GraphState.prompt`**：`Annotated[str, UntrackedValue]` → **`Annotated[Dict[str, str], SectionPatch]`**（原字段名 `system_prompt`）。写入 `None` 表示删除该键。
- **`context_compactor` 拆分**：原 `compact` 一个节点兼做「判阈值 + 压缩」，现在 `should_compact` 只管判、`compact` 只管压。`compact` 不再返回 `None`（进得来就是要压），也不再自己拼 `SystemMessage` —— 提示词由 `prompt_builder` 负责。
- **`on_turn_start` 的跳转目标**：`ON_BEFORE_REQUEST` → **`ON_BEFORE_COMPACT`**，轮开始先进压缩链路。
- **`context_compactor` 的注册点**：`on_before_request(compact)` → `on_before_compact(should_compact)` + `on_compact(compact)`。
- **`account_injector` 的产出**：返回 `{"prompt": {"account_info": ...}}` 而不是拼好的整串。

## Removed

- **`core/graph/`**（`graph_pipeline.py` + `actions/` 4 个文件）—— 迁入 `miaoli_pipeline`。
- **`errors/agent_aborted.py`** —— 迁入 `miaoli_pipeline.errors`。
- **`models/runtime/handler.py`** —— 迁入 `miaoli_pipeline.runtimes`。

## Fixed

- **多个节点写提示词时后者静默覆盖前者**（[issue #2](https://github.com/lyt2011/miaoli_bot/issues/2)）。`system_prompt` 是普通键、没有 reducer，谁最后写谁生效，前面的内容直接丢。改用 `miaoli_pipeline` 的 `SectionPatch` 自定义通道修复 —— 按 key 打补丁，各节点写各自的段，互不覆盖。

## Note

- **`miaoli_pipeline` 尚未发布到 PyPI**，因此没有写进 `manifest.toml` 的 `pip_dependencies`（那里只认「包名 + PEP 440 约束」，写 git URL 会让自动安装失败）。部署时手工装一次：`pip install "git+https://github.com/lyt2011/miaoli_pipeline.git"`。
- **压缩链路有循环风险**：`on_after_compact` 跳回 `ON_TURN_START` 会再进一次守卫。压缩后 token 仍超限时（`keep_count` 过大、压缩无效果、`max_tokens` 配得过大）会 `guard → compact → after_compact → turn_start → guard` 无限循环，直到 `GraphRecursionError`。目前没有「本轮已压缩过」的兜底标记。
- **`prompt` 段内不允许出现 `Overwrite`**：`SectionPatch` 的语义是「按 key 打补丁」，与「整体替换」互斥，`update()` 收到 `Overwrite` 会当场 `TypeError`。
