# v0.32.2 - 2026-10-31

> 🧹 **把 `search_memes_by_tags` 删掉之后留下的尾巴收干净**。0.30.0 删掉了那个工具，但 `MemeSqlite` 里为它服务的方法和 SQL 常量、子插件的权限条目都还留着 —— 全链路零调用。顺带补掉全仓最后一条 ruff 报错，并把拓扑排序的两个函数名收敛成一个。

## Changed

- **`tp_sort2` → `topology_sort_plugins`**（`core/plugin/loader.py`）：`tp_sort` 已经删掉，只剩一个实现就不需要「v2」这种编号后缀了。`Loader.load_plugins` 的调用点同步。
- **`tool_permission_manager/README.md`**：权限表示例里的 `search_memes_by_tags` 换成仍然存在的 `list_memes`，`anyone` 这一档仍有示例可循。

## Removed

- **`MemeSqlite.fetch_memes_by_tags`**（`meme_ops/core/meme_sqlite.py`）：`search_memes_by_tags` 工具删掉后零调用。
- **`MemeSqlite._fetch_meme_ids_by_tags` / `_fetch_meme_infos_by_ids`**：只被 `fetch_memes_by_tags` 调用，随之失效。
- **`FETCH_MEME_IDS_BY_TAGS` / `FETCH_MEME_INFOS_BY_IDS`**：只被上面两个方法用到的 SQL 常量。
- **`tool_permission_manager/config.yaml` 的 `search_memes_by_tags` 条目**：工具已不存在，这条权限声明永远匹配不到东西。
- **旧 `tp_sort`**（`core/plugin/loader.py`）：与 `topology_sort_plugins` 重复，保留两套实现只会让人犹豫该改哪个。

## Fixed

- **`ob11_adapter/nodes/event_adapter.py`**：`LOGGER.warning(f"没有可用 event 对象 跳过 ob11 解析")` 的 `f` 前缀没有占位符（ruff F541），去掉后全仓 `ruff check --select F,E9` 干净。
