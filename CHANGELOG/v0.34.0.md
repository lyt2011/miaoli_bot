# v0.34.0 - 2026-11-02

> 🧱 **包结构收拢到 `core/`，并新增一个只做「到点叫谁」的调度器**。`stores/` / `protocols/` / `adapters/` 三个顶层目录不再独立存在，`SHARE_STORE`、`PluginProtocol`、checkpointer 适配器分别并进 `core/` 下对应的位置。

## Added

- **`core/scheduler/`**：自研的最小调度器，只覆盖「某个时刻跑一次」与「每 N 秒跑一次」
  - `Job`：一个 `func` + 一个 `timer` 的调度循环，`launch()` / `stop()` 支持幂等，`is_running` 判活
  - `BaseTimer`（Protocol）：唯一方法是 `next_fire_time(now, previous)`，返回 `None` 表示不再触发
  - `Once` / `Every`：分别对应单次与间隔两种计时器
- `core/plugin/protocols/__init__.py`、`core/check_pointer_adapters/protocols/__init__.py`：补上缺失的包入口

## Changed

- **全局共享容器**：`stores/_share_store.py` → `core/_share_store.py`
- **插件协议**：`protocols/abc/plugin.py` → `core/plugin/protocols/plugin.py`
- **checkpointer 适配层**：`adapters/check_pointers/` → `core/check_pointer_adapters/`；`protocols/abc/checkpointer_adapter.py` → `core/check_pointer_adapters/protocols/checkpointer_adapter.py`
- **导入层级收敛**：子插件一律只碰主包 1 层，18 个子插件的 `main.py` 由 `miaoli_bot.protocols` / `miaoli_bot.core.plugin` 改为 `miaoli_bot.core`
- `api/` 的 6 个模块、`core/registries/handler_registry.py`、`main.py` 的 `SHARE_STORE` 导入改指 `core`
- `core/__init__.py` 增加 `SHARE_STORE` / `PluginProtocol` 导出；`core/`、`core/plugin/`、`core/check_pointer_adapters/`、`core/scheduler/` 的 `__all__` 按来源模块分组；根 `__init__.py` 挂上 `core`
- 全仓 116 行 `from ... import` 的 `import` 关键字按 tab stop = 4 对齐

## Removed

- `stores/`（含 `__init__.py` 与 `_share_store.py`）
- `adapters/`（并入 `core/check_pointer_adapters/`）
- `protocols/abc/store.py` —— 只有 `_ShareStore` 一个实现，抽象层没有存在意义
- `protocols/abc/plugin.py`、`protocols/abc/checkpointer_adapter.py`（迁移，非删除）

## Note

- **破坏性**：`miaoli_bot.stores` / `miaoli_bot.protocols` / `miaoli_bot.adapters` 三个导入路径全部失效，外部插件必须改到 `miaoli_bot.core` 对应位置。
- 调度器的定位是「到点叫谁」，不含持久化、错过补跑、cron 表达式，也没有独立发行计划 —— 它只服务本仓库的定时需求。
