# v0.35.0 - 2026-11-02

> 🔀 **LLM 客户端从写死 `ChatOpenAI` 变成按配置选实现**。`Provider.protocol` 换成 `Provider.client`，由 `api.build_client()` 统一建实例；顺带把 `api/` 按职责拆成一组 `*_ops`，并把三个名字说不清职责的子插件改成描述性名字。

## Added

- **`Provider.client`**（`Literal["openai", "deepseek", "anthropic"]`）：声明这个供应商用哪家的客户端实现
- **`api.build_client(provider_name=None, model_name=None)`**：按根配置现建客户端，三个实现在 `CLIENT_MAPPING` 里映射 —— `ChatOpenAI` / `ChatDeepSeek` / `ChatAnthropic`
- **`api/config_ops.get_root_config()`**：取根配置对象（`PluginConfig`）
- **`api/lock_ops.get_invoke_lock(thread_id)`**：取会话级执行锁
- **`errors/` 三个异常**（均继承 `BaseBotError`）：`ProviderNotFound`（供应商未在配置中声明）、`ModelNotFound`（供应商下没有声明的模型）、`ClientNotFound`（没有与该客户端对应的适配器）
- `manifest.toml` 的 `pip_dependencies` 新增 `langchain-deepseek`（`>=1.1.1`）与 `langchain-anthropic`（`>=1.0.0`）

## Changed

- **`plugins/base_nodes/nodes/build_client.py`**：改为调 `miaoli_bot.api.build_client()` 从根配置建实例，不再读 state 里的 `base_url` / `api_key` / `model` / `max_tokens`
- **`api/sugar.py` → `api/llm_ops.py`**：与其余 `*_ops` 模块同一命名规则；同时导出 `build_client`
- **`api/platform_ops.py`**：只留 `get_ncatbot_api`；`get_invoke_lock` 移到 `lock_ops`、`get_root_config` 移到 `config_ops`
- **`plugins/miaoli_bot_adapter`**：撤掉 `inject_model_info` 节点，只剩 `inject_soul` / `inject_output_protocol` 两个节点；`on_load` 解析出的根配置继续放 `SHARE_STORE`，由 `api.get_root_config()` 取
- **三个子插件改名**（目录 / `metadata.toml` 的 `name` / 入口类同步）：
  - `inject_time` → `time_injector`（`CurrentTimeInjector` → `TimeInjector`），与 `account_injector` 统一成「名词 + er」
  - `base_topology` → `default_routing`（`BaseTopology` → `DefaultRouting`），它做的事就是「没人插手时事件往哪走」
  - `base_system_tools` → `system_tools`（`BaseSystemTools` → `SystemTools`），`base_` 是无信息前缀
- `plugins/*/README.md`、`config.example.yaml` 头部注释、`tool_permission_manager/config.yaml` 的分组注释同步新名字

## Removed

- **`Provider.protocol`**（`Literal["openai-completions", "openai-responses"]`）：全仓零消费方，`build_client` 一直硬编码 `ChatOpenAI`
- **`plugins/miaoli_bot_adapter/nodes/inject_model_info.py`**：职责并入 `api.build_client()` + `build_client` 节点
- **`errors/pipeline_stop_dispatch.py`**（`PipelineStopDispatch`）与 **`errors/session_manager_closing_error.py`**（`SessionManagerClosingError`）：没有消费方

## Note

- **破坏性**：`providers[].protocol` 全部要换成 `providers[].client`（`openai` / `deepseek` / `anthropic`）。`Provider` 没有设 `extra="forbid"`，老配置里的 `protocol` 会被静默忽略，但缺 `client` 会 `ValidationError` 直接加载失败
- **破坏性**：三个子插件目录改名，各部署环境里未入库的 `plugins/<name>/config.yaml` 要跟着挪（内容不用改）
- `api/sugar.py` 这个导入路径不再存在；子插件从 `miaoli_bot.api` 取的符号不变（`get_model_info` / `get_provider_info` 照旧，只多了一个 `build_client`）
- `ChatDeepSeek` 是三个实现里唯一会把 `reasoning_content` 放进 `additional_kwargs` 的；要用思维链就用 `client: deepseek`
