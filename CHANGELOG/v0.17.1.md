# v0.17.1 - 2026-10-16

> 🎭 **提示词资产更新：新增 `prompt_v1.5.md`，显著压住「说几个字就输出一大串文本」的倾向**；顺带给发送逻辑加了个分块兜底。

### Changed

- **`main.py` 发送逻辑加兜底**：每块发送前先 `content_part.strip()` —— 分隔符是字面 `\n\n`，模型偶尔多敲一个换行（`\n\n\n`）时切出的块会带残换行，`strip()` 保证块首尾不留空白

### Added

- **`data/prompts/prompt_v1.5.md`**（v1.4 的迭代）：针对「像真人一样聊天（短、口语、一次别说完）」重写。要点：① 在「角色介绍」后加一句基调「我聊天的时候就像在手机上发消息：说一句、发出去、看对方回什么、再接着聊」；② 新增 `# 我怎么聊天` 段，把许可性的「我可以简短回应」换成默认性的「我懒得一条消息打一大段」，并给「打招呼一句 / 简单问题只答核心 / 要求详细才展开」三条场景规则；③ 「习惯」里 `无论什么时候都简短` → `按对方这句话的需要来`；④ 恢复 v1.3 被删掉的「口癖/表情/嘲讽在严肃时可少用一点」；⑤ 结尾加一句「一次只说一件事，说完就发出去，想再说第二件就另起一段」

### Note

- **实测对照**（`deepseek-flash`，同 4 组输入 × 3 遍，均值）：

  | 输入 | v1.3 | v1.4 | v1.5 |
  |---|---|---|---|
  | 你好 | 90 字 / 3.7 段 | 70 字 / 2.7 段 | **18 字 / 1.7 段** |
  | 代码报错 | 281 字 / 5.0 段 | 212 字 / 4.3 段 | **113 字 / 3.0 段** |
  | 情绪 | 70 字 / 3.3 段 | 46 字 / 3.0 段 | **30 字 / 2.7 段** |
  | 被夸 | 80 字 / 3.0 段 | 61 字 / 2.3 段 | **53 字 / 2.0 段** |

  「你好」：v1.3 / v1.4 都回「打招呼 + 吐槽 + 反问 + 颜文字」的小作文，v1.5 直接回 `干嘛～有事吗喵？`；正确性未退化（代码题仍答对核心 + 一句修法）。
- **踩的坑（分句分隔符）**：v1.4 里那句 `我必须使用`\n\n`作为每一句话的分隔符` 的**反引号**会让模型偶发把 `\n\n` 照抄成字面量文本，v1.5 改成不带反引号的中文描述后消失。另外「空两行」在中文里歧义大（人读 `\n\n\n`、模型读 `\n\n`）—— 实测模型稳定按 `\n\n` 理解，再加 `main.py` 的 `.strip()` 兜底，两种读法都不会出问题。
