# v0.30.1 - 2026-10-29

> 📖 **新增英文 README，中英两版在顶部互相链接**。内容与中文版同结构、同章节，供非中文读者和搜索引擎抓取。

本项目 README 一直是中文单版，GitHub 仓库页与外部搜索只拿得到仓库描述那一行。英文版按中文版的结构整体翻译（功能特性 / 架构图 / 目录结构 / 数据流 / 内置子插件 / 安装与使用 / 配置表 / 依赖 / 项目状态），技术标识符、字段名、优先级常量、路径一律保持原样，只在叙述上转成英文。

英文版放在 `README/en.md`，与 `CHANGELOG/` 的做法一致：根目录只留默认语言的入口文件，其它语言的正文收进同名目录。中文版仍是根 `README.md`（GitHub 渲染入口、搜索结果落地页），不搬进 `README/` —— 否则要么根目录变成空壳页，要么同一份正文存两遍。
