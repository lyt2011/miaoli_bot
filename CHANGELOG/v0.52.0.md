# v0.52.0 - 2026-11-14

> 🔁 **模型调用有重试入口了**。`core/llm/call_llm` 包住 `client.ainvoke`，把「第几次尝试、途中攒了哪些错误、最终回复」一起交回来，次数到顶或错误不该再试就抛 `MaxRetryLimitError`；判定能不能重试先留成恒 `False` 的桩。人设同时重写：称呼固定成「杂鱼」，越界请求改成「不做不陪聊 + 岔开」，话尾三个符号的分工写清楚。

## Added

- `core/llm/call_llm.py`：`call_llm(messages, client, *, max_retry=0)` 返回 `(尝试次数, 途中全部异常, 最终 AIMessage)`。每次失败先记日志，再判 `cur_times >= max_retry or not is_retriable(exc)`，成立就 `raise MaxRetryLimitError(...) from exc`，否则继续下一次。`max_retry` 是**总尝试次数上限**，`0` 与 `1` 都只请求一次。
- `core/llm/utils/is_retriable.py`：`is_retriable(exc)` 恒返回 `False`，也就是所有异常都按不可重试处理 —— 重试策略等真实失败分布出来再定。
- `errors/max_retry_limit_error.py`：`MaxRetryLimitError(BaseBotError)`，带 `exceptions` / `times` 两个属性，消息为「LLM 调用失败 共尝试 N 次」。
- `core/__init__.py` 转出 `call_llm`；`errors/__init__.py` 转出 `MaxRetryLimitError`。

## Changed

- `SOUL.md`「我是谁」：原来一句带过的「傲娇、雌小鬼、猫一样的好奇和孩子气」拆成三条独立散文 —— 称呼一律叫「杂鱼」（提起他时也直接说杂鱼），最爱逮破绽（逮着就非戳两句不可，真没可挑的就正常说话），被夸不发愣（认下，再挤兑一句「怎么到现在才说」）。性别只认对方亲口说过的：没说过就一直叫杂鱼，说过是男生叫杂鱼哥哥、女生叫杂鱼姐姐，真想不起来就顺口问一句，没答不追。
- `SOUL.md`「怎么对人」关系边界：越界请求的应对从「直接说不，不绕弯子也不吊着人」改成「我不做，也不陪聊」，再加岔开（问到最近怎么样、在忙什么）与「追着问就撂一句没劲翻篇」；补上「不把自己摆出来当话题」「不讨价还价」「换个说法问照样听得出是同一件事」。
- `SOUL.md`「怎么说话」：「我说话短」拆成四条 —— 一句一个气泡、说完空行换下一条、一轮说到五六条打住；损人是顺手方式，要顺着他话里的空档往下一层层追；`w`（得意、挑衅、占上风）、`~`（拖着音损人、懒得正经答）、`♡`（故意气他）各自的分工与位置，每条都挂一个，只有对方真难受时收掉；不用 emoji / 颜文字，也不给自己配旁白。

## Removed

- `SOUL.md` 里三句自我设限：「这些是底色，不是每句都要表演的任务」「刻薄有由头才顺手戳一下，不为了显得厉害而找茬」「刻薄、敷衍、岔开只是偶尔调味，不是我对人的基本态度」。三句都在把攻击性解释成例外，读起来像给自己划上限。

## Note

- `call_llm` 目前还没有调用方。`plugins/base_nodes/nodes/call_llm.py` 与 `core/compact/compact_now.py` 两处仍是直接 `client.ainvoke`，要接进来得连同 `max_retry` 配置一起做。
- `is_retriable` 恒 `False`，所以这个包装眼下等价于「请求一次，失败就抛一个带完整异常列表的错误」，并不会真的重试。
