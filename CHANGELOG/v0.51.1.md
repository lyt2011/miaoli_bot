# v0.51.1 - 2026-11-14

> ✏️ **工具调用展开成行时改用箭头**：`$name($args)` → `$name -> $args`。参数本身几乎总带括号（`{"cmd": "ls"}`），原来的写法会输出 `bash({'cmd': 'ls'})`，行尾连着模板的收尾括号，视觉上多套了一层。

## Changed

- `core/compact/consts/labels.py`：`TOOL_CALL_LABEL` 从 `"$name($args)"` 改成 `"$name -> $args"`。这行文本同时进两处 —— `ChatHistory` 生成的压缩请求历史正文，以及 `estimate_message_tokens` 的 token 估算 —— 改一处两边同步生效。

## Note

- `$` 只替换模板里的占位符，替换值里的 `$` 不会被二次展开，`{"cmd": "echo $HOME"}` 这样的参数原样保留。
- 只动常量字面量，剪枝与估算逻辑未改。同一条 `bash` 调用的估算值从 8.93 变 9.87（模板多 2 个字符），属于记账口径内的正常浮动。
