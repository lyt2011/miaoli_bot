# v0.22.2 - 2026-10-20

> 🧱 **修复人设提示词从未进入上下文**。0.22.0 改写 `inject_account` 时把 `get_prompt()` 丢了。

`inject_account` 在 0.21.0 的产出是「账号信息块 + 人设全文」拼成的整串。0.22.0 把它改成写 `prompt` 的 `account_info` 段，但只保留了账号信息那一半：

```python
# 0.21.0
return { "system_prompt": "\n\n".join([account_info, get_prompt()]) }

# 0.22.0
return {"prompt": {"account_info": account_info}}
```

`get_prompt()` 从此**零调用方**，根配置 `prompt_file` 指向的 `data/prompts/prompt_v1.7.md` 那 88 行人设一个字都没进 `SystemMessage`。模型只收到 `<account_info>` 一个段，人设完全缺失。

## Fixed

- 新增 `miaoli_bot_adapter` 的 `inject_soul` 节点（`on_turn_start`，`priority=NORMAL + 1`）：调 `miaoli_bot.api.get_prompt()` 读根配置人设全文，写进 `prompt` 的 `soul` 段。`prompt_builder` 在 `on_before_request` 拼装时自然带上它。
- 人设的归属从 `account_injector`（账号信息）移到 `miaoli_bot_adapter`（根配置适配）—— 人设是根配置里的数据，与账号信息无关。

## Docs

- `plugins/miaoli_bot_adapter/README.md`：补「节点」章节，说明两个节点各自的产出与为什么必须排在 `build_client` 之前。
- `README.md`：架构图、目录结构、功能特性、子插件表四处同步 `inject_soul`。

## Note

- `inject_soul` 与 `inject_model_info` 同优先级（`NORMAL + 1`）、同事件。两者互不依赖，顺序无关。
- `prompt` 段名是 `soul` 而不是 `persona` / `system` —— 与 `account_info` 一样，段名只影响 `SystemMessage` 里的 XML 标签，不影响行为。
