# v0.19.1 - 2026-10-18

> 📝 **修复提示词里的人设自相矛盾**：性格段写「张口就喜欢叫对方『雑魚』」，习惯段又写「我喜欢直接称呼对方的名字喵」，两句话互相打架。本版给前者补上限定，明确「叫雑魚」是带嘲讽意味的特例，不再与「直接称呼名字」冲突。

## Fixed

- **`data/prompts/prompt_v1.6.md` 第 28 行的人设冲突**：原文只有「看谁都是『雑魚』喵，张口就喜欢叫对方『雑魚』喵w」，与第 65 行「我喜欢直接称呼对方的名字喵」直接矛盾 —— 同一个模型读到两条互斥的行为准则，实际表现取决于上下文里哪条权重更高，不稳定。改为在句末补上限定：

  ```
  看谁都是"雑魚"，张口就喜欢叫对方"雑魚"喵——虽然我也可以直接称呼对方名字，
  但叫对方"雑魚"更能体现出「嘲讽」的意思喵 ≥﹏≤
  ```

  这样两条规则不再互斥：**默认称呼名字**（习惯），**想嘲讽时改用「雑魚」**（性格）。顺带删掉原句末尾一个多余的「喵」，避免同句出现两个语气词。
