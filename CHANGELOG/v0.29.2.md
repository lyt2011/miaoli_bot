# v0.29.2 - 2026-10-29

> 🧱 **`Loader` 的三个容器改成只读属性对外暴露**。之前只能靠 `is_prepared` / `is_loaded` / `is_erred` 单点判断，想看全貌得直接读 `_prepared` / `_erred` / `_loaded` 私有字段。

属性返回的是列表副本（容器本身仍是 `set` / `List`，写入还是走 `mark_*`），所以外部拿到的快照不会被后续加载过程改掉。

顺带把两处内部遍历改成走属性：`load_plugins` 的 `tp_sort()` 拿到的是 `list` 而不是 `set`（`set` 没有 `__next__`，严格讲不满足 `Iterator`），`unload_plugins` 反向遍历的是副本，循环体里 `_loaded.remove()` 不再影响正在遍历的序列。

## Added

- `Loader.erred` / `Loader.prepared` / `Loader.loaded`：三个只读属性，分别返回 `_erred` / `_prepared` / `_loaded` 的列表副本。
- `main.py` 的 `on_close`：卸载时若有子插件在加载阶段失败，打一条 warning 列出这些子插件的包名。

## Changed

- `Loader.load_plugins`：`tp_sort(self._prepared)` → `tp_sort(self.prepared)`。
- `Loader.unload_plugins`：`for plugin in self._loaded[::-1]` → `for plugin in self.loaded[::-1]`。
