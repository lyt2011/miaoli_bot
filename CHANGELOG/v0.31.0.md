# v0.31.0 - 2026-10-30

> 🧩 **没有 event 时不再丢弃整轮，每个会话的执行锁进共享容器**。前者是 bug：`ob11_adapter` 把「上下文里没有 event」当成终止，导致任何不来自 QQ 消息的调用（主动唤醒、定时任务）都走不完图；后者是一次语义收口：原来叫 `session_locks` 的锁其实保的是「一次图执行」，改名并把句柄放进 `SHARE_STORE`，外部插件才能和 `on_message` 抢同一把锁。

## Added

- **`api/pipeline_ops.py`**：新增 `get_pipeline()`，从共享容器取图管线。
- **`api/platform_ops.py` 的 `get_invoke_lock(thread_id)`**：按会话取执行锁，返回的就是 `on_message` 用的那一把（容器里是 `defaultdict(asyncio.Lock)`）。
- **`consts/INVOKE_LOCKS`**：新增共享容器 key `miaoli_bot/core.invoke_locks`。

## Changed

- **`session_locks` → `invoke_locks`**（`main.py`）：这个名字原来暗示「一个 QQ 会话一把锁」，实际保护的是「同一 thread 上的一次图执行」。`on_message` 与外部调用（如 smart_waker 的主动唤醒）都要拿它，语义按用途命名才对得上。
- **`invoke_locks` 进共享容器**：`on_load` 里 `SHARE_STORE.set(INVOKE_LOCKS, self.invoke_locks)`，`on_close` 里一并 drop，保持容器平衡。
- **`on_message` 的 `context` 不再传 `client: None`**：`client` 由 `build_client` 节点在运行时写入 `runtime.context`，入口处传 `None` 又立刻被覆盖，没有意义。现在入口只传 `{"tools": ...}`。
- **`base_system_tools` 的四个工具返回值改成字符串**：`read_file` / `replace` / `write` / `read_image` 不再返回 `{"status": bool, "message": ...}`，成功直接给正文，失败给 `[错误描述]`。`read_image` 成功时那条 `text` 段也改成 `[图片已添加到上下文中]`。
- **`api/__init__.py`** 导出 `get_pipeline` / `get_invoke_lock`。

## Removed

- **`store_recall` 里那句自定义 `KeyError`**：原实现先算 `SHARE_STORE.recall(key, default=default)` 再判断，改 `default` 语义后那句判断引用了一个不存在的 `value`，每次调用都 `NameError`。现在直接按 `default` 是否传入分两路转发。

## Fixed

- **`ob11_adapter` 没有 event 就丢弃整轮**：`event_adapter` 原来 `return Abort(reason="上下文里没有 event 对象")`，直接把图掐断。改成「跳过解析」返回 `None`，图继续往下走 —— 主动唤醒这类没有 QQ 事件的入口才有机会跑完。
- **`event_adapter` 的 `LOGGER` 从未定义**：新加的跳过分支里调 `LOGGER.warning`，但模块里没有 `LOGGER`，每次都 `NameError`（被 `GraphPipeline._dispatch` 的 `except Exception` 兜住，所以功能看着正常、日志一直是异常堆栈）。补了 `logging.getLogger("OB11Adapter")`。
- **`store_recall` 的 `NameError`**（见 Removed）。
- **`write` / `read_file` 的返回注解**：函数体早就在返回字符串，注解还写着 `Dict[str, str]` / `Dict[str, Any]`，一并改成 `str`，删掉随之失效的 `typing` 导入。

## Note

- **工具返回值现在是混的**：`base_system_tools` 的四个工具给字符串，`qq_platform_tools` / `meme_ops` / `web_search` 的工具还是 `{"status": bool, ...}` 字典。模型得按工具名记两种格式。
- **`GraphRuntimeContext` 的 `client` / `event` 改成 `NotRequired`**：入口只传 `tools`，`client` 由 `build_client` 运行时补；`event` 目前没有节点从 `runtime.context` 里读。
- `event_adapter` 的返回注解同步为 `Optional[Union[Dict[str, Any], Abort]]` —— 它现在确实会返回 `None`。
