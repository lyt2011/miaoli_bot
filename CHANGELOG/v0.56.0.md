# v0.56.0 - 2026-11-17

> 🧱 **提示词里只剩人设**。输出协议资产 `output_protocol.md` 与它的注入节点 `inject_output_protocol` 一起删除，`prompts` 不再有 `output-protocol` 段。`SOUL.md` 整篇重写：只写「她是谁、怎么说话」，不再出现渠道名、平台名与任何输出格式约束。

## Changed

- `plugins/miaoli_bot_adapter/data/SOUL.md`：整篇重写，4 节 1731 字符 → 10 节 2268 字符。新结构按第一人称小标题展开（我是谁 / 怎么叫对方 / 平常说话 / 捡到机会再补刺 / 互喷 / 嘴硬手软 / 颜文字 / 写代码 / 承认身份 / 拿不准时开口）。内容只描述角色本身，不再出现渠道、平台、消息条数、字数上限、回合节奏这类描述；颜文字池写进一个 `text` 围栏，正文不再用行内代码包裹颜文字。
- `plugins/miaoli_bot_adapter/nodes/__init__.py`：`__all__` 去掉 `inject_output_protocol`。
- `plugins/miaoli_bot_adapter/main.py`：`from .nodes` 的导入去掉 `inject_output_protocol`。

## Removed

- `plugins/miaoli_bot_adapter/data/output_protocol.md`：整份删除（48 行）。长度 / 接话 / 符号 / 分寸 / 消息边界 / 回复通道 / 输出格式这些条款不再作为提示词资产存在。
- `plugins/miaoli_bot_adapter/nodes/inject_output_protocol.py`：整个节点删除（21 行），`on_turn_start` 上不再有 `output-protocol` 的写入。
- `plugins/miaoli_bot_adapter/main.py`：`registry.on(ON_TURN_START, inject_output_protocol, priority=MEDIUM)` 这条注册删除。

## Note

- **`prompts` 的段少了一个。** 现在由本子插件写入的只有 `soul`；`time-inject-helper` / `meme-helper` / `available-memes` / `web-search-helper` / `account-info` 等段仍由各自的子插件写。`prompts` 走 `UntrackedSectionPatch`（`checkpoint()` 返回 `MISSING`），不落盘，所以不存在旧 `output-protocol` 残值跟着老会话继续拼进系统提示词的问题。
- **部署时 `data/` 下只剩一个文件。** `inject_soul` 是无条件 `read_text`，`SOUL.md` 缺失会在 `on_turn_start` 抛 `FileNotFoundError`；`output_protocol.md` 不再需要，留着也不会被读。
- **输出不再受框架约束。** 层里没有替代的格式约束节点：说多长、要不要分条、怎么标点，都由人设与模型自己决定；要按渠道分条的话由渠道在 `reply` 侧自己切。
- 本子插件的字段与容器键没有变（`enable` / `PLUGIN_CONFIG` / `RAW_CONFIG` / `WORKSPACE`），`WORKSPACE` 现在只被 `inject_soul` 用来拼 `data/SOUL.md` 的路径。
