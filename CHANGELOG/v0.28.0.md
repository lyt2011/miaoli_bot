# v0.28.0 - 2026-10-21

> 🧱 **状态通道 `prompt` 改名为 `prompts`**。`intent_recognition` 修掉工具循环里被工具返回值覆盖的匹配 bug，`meme_ops` 用常驻的 `available_memes` 段取代 `list_memes` 工具。

`prompt` 通道装的是 `Dict[str, str]` —— 一组互相独立的提示词段，不是「一个提示词字符串」。旁边 `messages` 是复数、装的也是多条消息，一单一复读起来容易误判成「单条提示词」。语义上它是复数，就按复数命名。

`SectionPatch` 通道由 `GraphState` 的 `Annotated` 注解自动注册，通道名即字段名，改名不需要额外代码。各段都是每轮现拼、不跨轮累积，改名不影响任何持久状态。

## Added

- `plugins/meme_ops/nodes/inject_memes.py`：挂在 `on_agent_start`（`NORMAL`），把已归档表情包的 `hash: description` 列表拼进 `prompts` 的 `available_memes` 段。

## Changed

- `models/graph_state.py`：通道 `prompt` 改名为 `prompts`。
- `plugins/prompt_builder/nodes/build_prompt.py`：改读 `state["prompts"]`，docstring 同步。
- `plugins/account_injector/nodes/inject_account.py`、`plugins/miaoli_bot_adapter/nodes/inject_soul.py`、`plugins/meme_ops/nodes/inject_doc.py`、`plugins/intent_recognition/nodes/recognize_intent.py`：注入返回值改用 `prompts` 键。
- `plugins/intent_recognition/nodes/recognize_intent.py`：改为用 `get_latest_human(messages)` 回溯最近一条用户消息作为匹配对象，不再取 `messages[-1]`。摘要文件末尾的裸路径后缀改为无条件追加。
- `plugins/meme_ops/main.py`：注册 `on_agent_start(inject_memes)`，不再注册 `list_memes` 工具。

## Removed

- `plugins/meme_ops/tools/list_memes.py`：清单改由 `inject_memes` 常驻注入，不再需要模型为「先看有什么」多跑一轮工具调用。
- `plugins/intent_recognition/models/plugin_config.py`：删除 `with_path` 字段。来源标记改为无条件追加 —— `GUIDE` 已经明确要求读取 `(from <file>)` 给出的路径，把它做成开关会让引导语在关闭时指向不存在的路径。

## Fixed

- `intent_recognition` 的匹配对象错位：节点挂在 `ON_BEFORE_REQUEST`，而工具循环会从 `ON_TOOL_CALLING` 回到 `ON_TURN_START`，一个用户回合会跑多次 `ON_BEFORE_REQUEST`。第二次起 `messages[-1]` 已经是工具返回值（表情包清单、`message_id` 之类），按它重算得到「不命中」，把本轮已注入的段覆盖成空 —— 模型在写最终回答时看不到参考资料，退化成编造。改为回溯最近一条 `HumanMessage` 后，任意轮次重算结果一致。

## Note

- `utils/helper.py` 新增 `get_latest_human(messages)`，`utils/__init__.py` 导出。
- `plugins/intent_recognition/config.example.yaml` 删除 `with_path` 一行。该配置是 `extra="forbid"`，照抄带 `with_path` 的模板会直接 `ValidationError`。
- `core/registry.py` 删除两个未使用的导入（`TOOL_REGISTRY`、`SHARE_STORE`）。

- `plugins/meme_ops/README.md`：节点表补充 `inject_memes`；「为什么需要它」一节改写为常驻清单的现状，`prompt` → `prompts`。
