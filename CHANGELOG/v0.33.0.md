# v0.33.0 - 2026-11-01

> 🎭 **人格与输出协议从主包里剥出来了**：`data/prompts/`、根配置的 `prompt_file`、`api.get_prompt` 全部删除 —— `miaoli_bot` 从此只管 QQ agent 的收发框架，不再持有任何提示词资产。人格（`SOUL.md`）与输出协议（`output_protocol.md`）改由 `miaoli_bot_adapter` 子插件持有，每轮读盘写进 `prompts` 的对应段。
> 同版本还落地了子插件配置的 `$workspace` 占位符、新增 `inject_time` 子插件，并把 `sub_plugin.load_from` 收紧成 `DirectoryPath`。

## Added

- **子插件 `inject_time`**（`plugins/inject_time/`）：`inject_current_time` 挂在 `on_turn_start`（`priority=NORMAL + 1`），每轮返回 `{"prompts": {"current_time": "年-月-日-小时-分钟-秒"}}`；`on_close` 对称摘除。自带 `README.md`。
- **`utils/config_ops.py`**：新增 `inject_workspace(data, workspace)`，对 `str` / `list` / `dict` 递归替换 `$workspace` 与 `${workspace}`（`string.Template.safe_substitute`）。不认识的占位符原样保留，非 `str` 值原样返回。
- **`Plugin._prepare_config`**（`core/plugin/plugin.py`）：`config.yaml` 解析后统一过一遍 `inject_workspace`，第二个参数是 `str(self.path)`。
- **`Plugin._inject_data`**：子插件实例上新增 `workspace` 属性（`self.path`，`Path` 对象），与已有的 `metadata` / `config` 并列。
- **`plugins/miaoli_bot_adapter/data/SOUL.md`**：人格资产，段名 `soul`，内容为身份 / 外貌 / 脾气 / 口吻四块。
- **`plugins/miaoli_bot_adapter/data/output_protocol.md`**：输出协议资产，段名 `output_protocol`，内容为长度 / 接话 / 松弛 / 符号 / 分寸 / 消息边界 / 回复通道 / 标点 / 语序 / 输出格式十块。
- **`nodes/inject_output_protocol.py`**（`miaoli_bot_adapter`）：挂在 `on_turn_start`（`priority=NORMAL + 1`），把 `data/output_protocol.md` 全文写进 `prompts` 的 `output_protocol` 段。
- **`consts.WORKSPACE`**（`miaoli_bot_adapter`）：新增 store 键 `miaoli_bot/subplugin/miaoli_bot_adapter.workspace`，`on_load` 时写入本插件目录，供两个提示词节点拼 `data/` 下的路径。

## Changed

- **`inject_soul` 换数据来源**：不再从根配置的 `prompt_file` 取人设，改成用 `store_recall(WORKSPACE)` 拿到插件目录后读 `data/SOUL.md`。
- **`sub_plugin.load_from` 的类型收紧**：`List[Path]` → `List[DirectoryPath]`。目录不存在 / 指向文件时，`PluginConfig.model_validate` 当场抛 `ValidationError`（`path_not_directory`，`loc` 精确到 `load_from` 的第几项），不再拖到 `Loader.expand_paths()` 里才 `path.iterdir()` 炸 `FileNotFoundError`。
- **`prompt_builder` 的段落渲染**：`<key>value</key>` → `<key>\nvalue\n</key>`，每段独立成行。
- **`miaoli_bot_adapter` 的节点数与职责**：两个节点变三个，插件同时成为人格资产的持有者；`metadata.toml` 的 `description` 对应改写。
- **`inject_model_info` 的 docstring**：`[OI]` 写全成 `OpenAIClient`。
- **`utils/sugar.py`**：`concatenate_id` 的两步拼接合并成一行 `f-string`，补上 docstring。行为不变。

## Removed

- **`data/prompts/` 整个目录**（8 个文件：`prompt_v1.0.md` ~ `prompt_v1.7.md`）。
- **根 `PluginConfig.prompt_file`**：`Optional[str]` 字段、`_prompt` 私有属性与懒加载的 `prompt` 属性一并删除，`pathlib.Path` / `PrivateAttr` / `Optional` 三个随之失效的导入清掉。
- **`api/sugar.py` 的 `get_prompt()`**：以及 `api/__init__.py` 里的导入与 `__all__` 条目。
- **`config.yaml` / `config.example.yaml` 的 `prompt_file` 键**。

## Note

- **部署时必须同步 `plugins/miaoli_bot_adapter/data/`**（`SOUL.md` 与 `output_protocol.md`）—— 少了这两个文件，`on_turn_start` 会 `FileNotFoundError`。
- **`sub_plugin.load_from` 里的每一条路径现在都必须真实存在**，包括部署机上的绝对路径。写错一个字母，`on_load` 第一步就过不去。
- 两份提示词都是**每轮读盘**，改完 `md` 不用改代码，下一轮就生效。
