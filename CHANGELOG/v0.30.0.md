# v0.30.0 - 2026-10-29

> 🧱 **删掉按标签检索表情包的工具，标签改为常驻注入**。`MemeSqlite` 的方法按语义重排、重命名，SQL 顺手收紧。

`search_memes_by_tags` 之前的作用是让模型自己按标签找图。但它和 `inject_memes` 重复:清单本来就已经常驻在 `available_memes` 段里,模型手里有全部 `hash` + 描述,再跑一轮工具循环去"搜标签"是多余的一次往返。删掉工具之后标签没有别的消费点,于是把它并进注入内容——每行从 `hash: description` 变成 `hash: description: tags`,模型看图时能同时看到标签,选图依据更足。

`MemeSqlite` 这次是纯重构:方法按「生命周期 → 读 → 写 → 内部查询」排,命名统一成 `fetch_*_by_*` / `has_*` / `add_meme` ↔ `remove_meme`。其中 `_fetch_meme_infos_from_tags` 原名是错的——入参明明是 `meme_id` 列表而不是 tags。

## Added

- `MemeSqlite.fetch_tags_by_meme_ids(meme_ids)`：由 `_fetch_tags_from_meme_ids` 改名并公开,批量取 `{meme_id: [tag, ...]}`,顺序按 `(meme_id, tag)` 排好,`inject_memes` 直接消费。

## Changed

- `MemeSqlite` 方法重排为 `__init__` / `__aenter__` / `__aexit__` → 读（`fetch_memes` / `fetch_meme_by_hash` / `fetch_tags_by_meme_ids` / `fetch_memes_by_tags` / `has_hash`）→ 写（`add_meme` / `remove_meme`）→ 内部查询（`_fetch_meme_ids_by_tags` / `_fetch_meme_infos_by_ids`）。
- 方法重命名：`is_hash_existing` → `has_hash`、`fetch_meme_from_hash` → `fetch_meme_by_hash`、`insert_meme` → `add_meme`、`query_tags` → `fetch_memes_by_tags`、`_fetch_meme_ids_from_tags` → `_fetch_meme_ids_by_tags`、`_fetch_meme_infos_from_tags` → `_fetch_meme_infos_by_ids`。
- SQL 常量重命名：`CHECK_HASH_EXISTENCE` → `HAS_HASH`、`FETCH_ALL_MEME` → `FETCH_ALL_MEMES`、`FETCH_ID_BY_HASH` → `FETCH_MEME_ID_BY_HASH`、原 `FETCH_MEME_ID_BY_HASH`（其实查整行）→ `FETCH_MEME_BY_HASH`；`IN (...)` 列表统一成带 `{placeholder}` 的 `FETCH_MEME_INFOS_BY_IDS` / `FETCH_TAGS_BY_MEME_IDS` / `FETCH_MEME_IDS_BY_TAGS`。
- `FETCH_ALL_MEMES` 加 `ORDER BY id`：注入顺序不再依赖 rowid。
- 标签过滤的 `HAVING COUNT(DISTINCT tag) = n` → `HAVING COUNT(*) = n`：`(tag, meme_id)` 是主键不会重复，Python 侧用 `dict.fromkeys` 去重并保留传入顺序。
- `fetch_tags_by_meme_ids` 不再用 `GROUP_CONCAT(tag, '§')` 拼字符串后 split：改成直接取 `(meme_id, tag)` 行在 Python 侧分组，标签里就算出现 `§` 也不会拆错。
- `add_meme` 写标签用 `dict.fromkeys(tags)` 代替 `set(tags)`：去重的同时保留顺序。
- `inject_memes`：每行改为 `hash: description: tags`，标签以列表字面量（`['a', 'b']`）原样拼入，多查一次 `fetch_tags_by_meme_ids`。
- 类型注解修正：`fetch_memes()` 返回 `List[Tuple[int, str, str, bytes]]`（原写成 4 个 `str`）、`add_meme(base64: bytes)`（原写成 `str`）、`_fetch_meme_ids_by_tags` / `_fetch_meme_infos_by_ids` 的 `meme_ids` 为 `List[int]`。

## Removed

- `plugins/meme_ops/tools/search_memes.py`（`search_memes_by_tags`）及其在 `tools/__init__.py` 的导出、`main.py` 的注册与 `on_close` 摘除：按标签检索的能力并入常驻注入，不再单独提供工具。

## Note

- `fetch_memes_by_tags()` 保留但当前无调用点（原本只被刚删掉的工具使用）。
- `fetch_memes()` 仍然会连 `base64` 一起查出来（生产库约 4.5 MB），而注入只用 `id / description / hash`。这次没动，要省可以再加一个只查三列的方法。
- `plugins/tool_permission_manager/config.yaml` 与它的 `README.md` 里仍留着 `tool_name: "search_memes_by_tags"` 的条目，配置未改。
